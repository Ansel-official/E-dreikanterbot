# 中国大陆公网部署：ICP 备案与合规清单

> **先说明**：本文是工程视角的操作清单，不构成法律意见，也不代办任何备案。备案能否通过由主管部门与接入商决定；请以接入商备案系统、工信部与属地管局的最新要求为准。涉及生成式 AI、算法、等保、个人信息保护时，建议咨询专业律师或合规顾问。

E-dreikanterbot 提供页脚展示位与配置项，但**不能代替你完成备案**。没有备案号就公开提供服务，存在被接入商阻断、责令整改或处罚的风险。

---

## 1. 先判断你需要哪些备案

| 事项 | 何时需要 | 主管/入口 |
| --- | --- | --- |
| **ICP 备案**（非经营性） | 使用中国大陆服务器，通过域名向公众提供互联网信息服务 | 接入服务商（阿里云/腾讯云/华为云等）代提交，管局审核 |
| **ICP 许可证**（经营性） | 通过互联网有偿提供信息或服务（会员费、广告、交易等） | 省通信管理局 |
| **公安联网备案** | 网站/App 上线后 | 全国互联网安全管理服务平台 `beian.mps.gov.cn` |
| **生成式 AI 服务备案/登记** | 面向境内公众提供生成式 AI 服务，具有舆论属性或社会动员能力 | 属地网信办，按《生成式人工智能服务管理暂行办法》 |
| **算法备案** | 具有舆论属性或社会动员能力的算法推荐/生成合成服务 | 互联网信息服务算法备案系统 |
| **等保测评** | 按系统定级，通常二级及以上 | 公安机关/测评机构 |
| **AI 生成内容标识** | 生成文本、图片、音视频等内容 | 《人工智能生成合成内容标识办法》（2025-09-01 施行） |

个人主体通常只能做非经营性备案，且部分省份对个人网站内容有额外限制；企业主体材料更完整。**不要用个人备案承载付费服务。**

---

## 2. ICP 备案前置条件

1. **主体**：企业营业执照，或符合属地要求的个人身份证。
2. **域名**：
   - 已完成实名认证（域名持有者与备案主体一致）；
   - 域名后缀在工信部许可名单内；
   - 域名未在其他主体名下备案。
3. **服务器**：中国大陆境内、有接入资质的云服务器/虚拟主机；需要接入商提供备案服务号。
4. **网站负责人**：需完成人脸核验/短信核验，部分省份要求幕布照或视频。
5. **网站内容**：不得涉及前置审批（新闻、出版、教育、医疗、药品、文化、广电等需先取得许可）。

> 香港/海外服务器不需要 ICP 备案，但面向大陆用户提供服务仍可能触发其他合规义务；本指南不展开。

---

## 3. ICP 备案流程（以接入商为例）

1. **注册接入商账号**，进入「ICP 备案」系统。
2. **填写主体信息**：证件、负责人、联系方式、应急联系人。
3. **填写网站信息**：域名、网站名称、服务内容、语言、IP。
4. **上传材料**：证件照、域名证书、负责人核验照、承诺书（按接入商模板）。
5. **接入商初审**：通常 1–3 个工作日，会电话核验。
6. **工信部短信核验**：收到 12381 短信后，在要求时限内完成核验。
7. **管局审核**：一般 1–20 个工作日（各省不同），期间保持电话畅通。
8. **下发备案号**：例如 `京ICP备2026000000号-1`。
9. **页脚展示**：在网站首页底部展示备案号，并链接到 `https://beian.miit.gov.cn/`。

### 本项目的页脚配置

```dotenv
ICP_NUMBER=京ICP备2026000000号-1
ICP_LINK=https://beian.miit.gov.cn/
POLICE_NUMBER=京公网安备 11010502000000号
POLICE_LINK=https://beian.mps.gov.cn/
SITE_URL=https://chat.example.com
CONTACT_EMAIL=you@example.com
```

- 未配置 `ICP_NUMBER` 时，页脚显示「ICP 备案待配置」，不会伪造备案号。
- 配置后，桌面侧栏、底部页脚、关于弹窗都会展示备案号并链接工信部。
- 备案号必须与实际主体、域名一致，不得转借。

## 4. 公安联网备案

网站开通后 **30 日内**登录 [全国互联网安全管理服务平台](https://beian.mps.gov.cn/)：

1. 注册/登录，选择「新网站备案」。
2. 填写网站名称、域名、IP、接入商、负责人。
3. 上传营业执照/身份证、域名证书、备案号截图。
4. 提交后等待属地网安审核，获得「公网安备」号。
5. 同样在页脚展示，并链接 `https://beian.mps.gov.cn/`。

## 5. 生成式 AI 相关义务

面向境内公众提供生成式 AI 服务，通常需要关注：

1. **服务备案/登记**：按《生成式人工智能服务管理暂行办法》履行备案；调用已备案大模型能力做应用，也可能需要登记。具体口径咨询属地网信办。
2. **算法备案**：具有舆论属性或社会动员能力的生成合成/推荐服务。
3. **内容安全**：
   - 使用官方 `safety_check: high`（本项目默认）。
   - 建立关键词/人工审核/投诉举报机制。
   - 对违法违规内容及时处置并留存记录。
4. **AI 标识**：
   - 按《人工智能生成合成内容标识办法》添加显式标识（如「AI 生成」）和隐式标识（元数据）。
   - 不得删除、篡改、伪造标识。
5. **训练数据与知识产权**：使用官方 API 时，训练数据由模型提供方负责；你的提示词、用户内容仍需合法来源。
6. **未成年人保护**：设置未成年人模式/提示，避免诱导消费与不适内容。
7. **个人信息保护**：最小化收集、告知同意、删除渠道、跨境传输评估。

> 本项目只负责技术实现；是否构成「具有舆论属性或社会动员能力」、是否需要备案，需结合你的实际服务形态判断。

## 6. 内容安全与运营制度（建议至少具备）

- [ ] 用户协议、隐私政策、未成年人保护条款
- [ ] 投诉举报入口与处理时限（建议 24 小时内响应）
- [ ] 关键词库 + 人工复审 + 违规处置流程
- [ ] 日志留存不少于 6 个月（《网络安全法》要求）
- [ ] 账号与访问控制、最小权限
- [ ] 数据备份与泄露应急预案
- [ ] 生成内容标识与溯源
- [ ] 不使用用户数据训练模型（如涉及，需单独告知同意）

## 8. 常见误区

- **「用了别人的 API 就不用备案」**：只要你在境内通过网站向公众提供服务，ICP 备案通常仍需要；生成式 AI 另有要求。
- **「备案号可以借」**：备案与主体、域名绑定，转借会被注销。
- **「海外服务器就没事」**：不需要 ICP，但仍可能涉及内容安全、个人信息、AI 标识等义务。
- **「备案一次就永久」**：主体/域名/接入商变更需变更备案；信息不实会被注销。

## 9. 本项目的边界

- 提供备案号展示位、`safety_check` 开关、内容安全默认值、日志与备份能力。
- **不提供**：代办备案、材料代写、规避审核、伪造备案号。
- 页脚未配置备案号时明确显示「待配置」，避免误导访客。

如有备案代办声称「包过」「不需要材料」，请提高警惕。
